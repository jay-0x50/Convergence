# 아스트랄 택틱스 (가제) — 기획서 v0.2

> 스타레일 & 원신 IP 기반 턴제 카드 전략 게임 (추후 타 게임 IP 확장 예정)
> 레퍼런스: 유희왕(전개의 다양성, 체인 시스템) + 원신 "일곱성인의 소환"(세계관 재현) + TCG 덱빌딩/가챠

---

## 1. 한 줄 컨셉

**"같은 덱이라도, 어떤 카드를 채용하느냐에 따라 완전히 다른 방식으로 전개되는 카드 게임."**

원신의 공식 TCG인 「일곱성인의 소환」은 캐릭터/원소 반응을 잘 재현했지만, 전개 방식이 사실상 정형화되어 있음(투력 관리 → 스킬 발동 → 원소반응 루틴의 반복). 본 게임은 이 틀을 깨고, **유희왕처럼 "덱 컨셉은 같아도 채용 카드에 따라 완전히 다른 게임 플랜이 나오는" 자유도**를 1순위 차별점으로 삼는다.

---

## 2. 차별화 포인트 요약

| 항목 | 일곱성인의 소환 (기존) | 아스트랄 택틱스 (본 기획) |
|---|---|---|
| 전개 방식 | 고정적 (원소 반응 루틴 중심) | 카드 채용에 따라 가변적 (아키타입 내 여러 빌드) |
| 덱 매수 | 20장 ~ 30장 | **20장 ~ 40장 자유 구성** |
| 메인 캐릭터 결정 | 플레이어가 직접 선택/고정 | **뽑기(가챠)로 매 대전 시작 시 랜덤 결정** |
| 상호작용성 | 낮음 (상대 턴 개입 제한적) | 유희왕식 **세트/발동 카드**로 상대 턴 개입 가능 |
| 전투 판정 | 원소 반응 표 기반 | **체인 시스템 하나로 통합** (원소 반응 별도 계산 없음) |
| 카드 획득 | 팩 구매 | **인게임 재화 구매 + 가챠 뽑기 병행** |

> 위 표의 3번째 줄 이후 항목은 이번 수정에서 새로 확정된 규칙이며, 세부 내용은 아래 각 섹션에서 다룸.

---

## 3. 세계관 및 진영 분류 체계

여러 게임에 나오는 보스 캐릭터 혹은 사용자 캐릭터들을 사용함.
카드는 큰 시리즈로 나뉘고, 각 시리즈 내부에서 "1차 분류(계통)"와 "2차 분류(속성)"로 세분화된다. 이 조합이 곧 **덱 아키타입 코드**가 된다.

> 속성/계통 분류는 **덱의 정체성(플레이버 + 서포트 카드 지정 조건)**으로만 기능하며, 전투 중 자동 계산되는 상성 반응 시스템은 두지 않는다 (상세는 8. 체인 시스템 참고).

### 3-1. 스타레일 계열 — 분류축: 운명의 길(命途)

| 계통 | 성격 키워드 |
|---|---|
| 파멸 | 광역이 아닌 방어력 기반 데미지, 자폭성 |
| 수렵 | 단일 고배율, 속공 |
| 지식 | 광역 연속 공격 혹은 격파, 축적형 딜 |
| 화합 | 버프, 팀 서포트 |
| 공허 | 디버프, 방해, 독·열상 등 지속 데미지 |
| 보존 | 방어, 실드, 지구전 |
| 풍요 | 턴이 지날수록 데미지 증가, 사용자 회복 |
| 기억 | 정령 소환 |
| 환락 | 추가 턴, 웃음 포인트 |

### 3-2. 원신 계열 — 분류축: 지역(國家)

몬드 / 리월 / 이나즈마 / 수메르 / 폰타인 / 나타 / 스네즈나야(예정) — 지역별로 **국가 특유의 정치/문화 기믹**을 계통 특성으로 부여한다. (예: 폰타인 = "심판/증거" 기반 카드 효과, 나타 = "화계"/전투 토너먼트 기반 즉발 효과)

**추후 다른 게임 추가 시 작성**

### 3-3. 공통 2차 분류 — 속성

- 스타레일: 물리 / 화염 / 얼음 / 번개 / 바람 / 양자 / 허수
- 원신: 불 / 물 / 바람 / 번개 / 풀 / 얼음 / 암석

### 3-4. 덱 아키타입 코드 예시

| 캐릭터(예시) | 계통 | 속성 | 특수 태그 | 아키타입 코드 |
|---|---|---|---|---|
| 은랑 999 (가상 예시) | 환락 | 허수 | 확률조작 | `환락-허수-확률` |
| 에바네시아 (가상 예시) | 환락 | 물리 | 소환 | `환락-물리-소환` |

**핵심 설계 의도:** 같은 `환락` 계통이어도, 은랑 999 덱은 "허수 속성 + 확률 조작"으로 상대 카드를 무력화하는 통제형으로, 에바네시아 덱은 "물리 속성 + 소환수 전개"로 물량 공세형으로 완전히 다르게 플레이된다. 계통(길/지역)은 "덱의 정체성", 속성+특수태그는 "덱의 실제 플레이 패턴"을 결정한다.

## 4. 카드 종류

유희왕의 몬스터/마법/함정 구조를 계승하되 세계관에 맞게 재명명.

| 카드 종류 | 유희왕 대응 | 설명 |
|---|---|---|
| **캐릭터 카드** | 몬스터 카드 | 공격/방어의 주체. 계통+속성 보유. 능력치는 **공격력 / 체력** 2종만 존재 |
| **커맨드 카드** | 마법 카드 | 즉시 효과. 버프/디버프, 자원 수급 등 |
| **인터셉트 카드** | 함정 카드 | 세트 후 조건 충족 시 발동. 상대 턴 개입용 |
| **유물/성유물 카드** | 장착 카드 | 캐릭터에 장착, 공격력/체력 수치나 지속 효과 부여 |
| **결계/도메인 카드** | 필드 카드 | 필드 전체에 영향 |
| **소환수 카드** | 엑스트라 덱 유닛 | 특정 조건 충족 시 필드에 추가 전개되는 서브 유닛 |

---

## 5. 덱 구성 및 드로우 규칙

- **덱 매수**: 20장 ~ 40장 사이에서 자유 구성 (기본 권장치 30장 — 밸런스 테스트 후 확정)
- **시작 핸드**: 4장 ~ 5장
- **드로우 페이즈**: 매 턴 1장씩 드로우 (유희왕과 동일한 리듬)
- 덱 매수 자유화로 인해 "적은 매수로 사고율을 높인 콤보 덱" vs "많은 매수로 안정성을 높인 롱게임 덱"이라는 또 다른 빌드 다양성 축이 자연스럽게 생김 → 3항의 계통/속성 축과 별개로 "덱 두께"도 전략 선택지가 되도록 유도.

---

## 6. 카드 획득 및 재화 시스템

카드 수집은 아래 두 경로를 병행한다 (배포/수익화는 현재 미정이지만, 설계 단계에서는 반영):

1. **직접 구매**: 인게임 재화로 원하는 카드를 상점에서 지정 구매
2. **가챠 뽑기**: 인게임 재화 또는 유상 재화로 랜덤 카드 뽑기 (확률형 아이템 방식)

> 6번(카드 획득 가챠)과 9번(대전 시작 시 메인 카드 랜덤 선정 연출)은 **서로 다른 시스템**임에 유의. 6번은 "덱에 넣을 카드를 모으는" 수집용 가챠, 9번은 "이미 모은 덱 안에서 이번 판의 주인공을 뽑는" 연출용 무작위 선정임.

---

## 7. 턴 진행 구조

유희왕 페이즈 구조를 그대로 채용. 원소 반응 판정을 위한 별도 페이즈는 두지 않고, 모든 카드 효과 발동/개입은 8번 체인 시스템으로 일원화한다.

1. **드로우 페이즈** — 카드 1장 드로우
2. **메인 페이즈 1** — 카드 전개, 커맨드 카드 발동, 캐릭터 소환/장착
3. **배틀 페이즈** — 공격 선언(캐릭터 카드의 평타 공격) → 인터셉트 카드 발동 가능 → 데미지 계산
4. **메인 페이즈 2**
5. **엔드 페이즈** — 지속 효과 정산

## 8. 체인 시스템 (원소 반응 대체)

- 원신식 원소 반응 표(증발/감전/동결 등)는 사용하지 않는다. **모든 카드 간 상호작용은 체인 하나로 통합.**
- 커맨드/인터셉트 카드는 유희왕처럼 **체인**으로 연쇄 발동 가능: 상대가 카드를 발동하면, 조건이 맞는 인터셉트 카드로 즉시 끼어들어 대응할 수 있음.
- 계통 시너지(예: 같은 계통 카드 다수 배치 시 버프)는 남겨두되, 이는 **상시 적용 조건부 효과**로 처리하고 별도의 "반응 판정 페이즈" 없이 필드 상태 갱신 시 자동으로 체크한다.
- 이 방식으로 게임의 개입 지점을 "속성 상성 계산"이 아니라 "카드 텍스트와 타이밍 싸움"에 집중시켜, 유희왕 특유의 심리전/타이밍 게임 느낌을 살린다.

---

## 9. 메인 카드 뽑기 시스템 (대국 시작 연출)

- 게임 시작 시, 자신의 덱에서 **"이번 판의 메인 캐릭터"** 1장을 랜덤 추첨(가챠 연출 UI)으로 결정.
- 메인 캐릭터는 다음 이점을 가짐:
  - 필드에 등장 시 계통 고유 연출/전용 대사
  - **평타 공격 시 전용 공격 애니메이션 부여** (일반 캐릭터 카드는 애니메이션 없는 기본 평타만 존재 — 상세는 10번 참고)
- 같은 덱이라도 어떤 캐릭터가 "메인"으로 뽑히느냐에 따라 그 판의 전략 방향이 달라짐 → 매 대국마다 재미와 변수 제공.
- (확장 아이디어) 메인 카드는 시즌제 "한정 스킨/한정 대사"로 차별화하여 뽑기 특유의 손맛과 수집 동기 부여.

## 10. 전투 시스템

### 10-1. 카드 능력치
캐릭터 카드의 수치는 **공격력(ATK) / 체력(HP)** 2종뿐. 별도의 방어력 수치는 두지 않으며, 방어적 플레이는 실드/무효화 등 카드 효과 텍스트로 구현한다.

### 10-2. 플레이어 라이프
플레이어는 카드 체력과 별개로 **개인 라이프(체력)**를 보유. 유희왕과 동일하게, 이 라이프가 0이 되면 패배.

### 10-3. 공격 방식
- 기본 캐릭터 카드는 **"평타" 공격 하나만** 보유 (스킬 선택지 없이 단일 공격 액션).
- **메인 카드(9번에서 뽑힌 카드)**는 이 평타에 전용 연출/애니메이션이 추가되어 시각적으로 구분됨.
- 이렇게 하면 카드 텍스트/효과는 커맨드·인터셉트 카드 쪽에서 다양성을 담당하고, 캐릭터 카드 자체의 전투 판정은 단순하게 유지되어 게임 진행 속도와 가독성을 확보.

### 10-4. 승리 연출 — 처형 모션
- 상대 플레이어의 라이프를 0으로 만들어 승리할 경우, **자신의 메인 캐릭터가 전용 "처형 모션(피니시 애니메이션)"을 재생**하며 게임이 종료됨.
- 뽑기로 얻은 메인 카드에 대한 애착과 승리의 쾌감을 동시에 강화하는 연출 장치로 활용.

## 11. 덱 구성 다양성 확보 방안 (전개 자유도)

같은 아키타입이라도 "빌드"가 갈리도록 카드 풀을 설계:

- **콤보형 빌드**: 특정 커맨드 카드 조합으로 한 턴에 폭발적 전개(유희왕의 콤보 덱 오마주)
- **컨트롤형 빌드**: 인터셉트 카드 다수 채용, 상대 전개를 방해하며 지구전
- **미드레인지/템포형 빌드**: 계통 시너지 극대화, 매턴 안정적 어드밴티지 축적
- **소환수 물량형 빌드**: 소환수 카드 중심으로 필드를 넓게 전개
- **덱 두께 변수**: 20장대의 얇은 덱(사고율↑, 콤보 안정성↑) vs 40장에 가까운 두꺼운 덱(변수 대응력↑, 롱게임 지향)

→ 하나의 계통(예: 환락)에서도 위 빌드가 전부 성립 가능하도록 카드 텍스트를 설계하는 것이 향후 카드 리스트 작업의 핵심 가이드라인.
