# Convergence — 듀얼 프로토타입

Unity 2D로 만드는 카드 대전 프로토타입이다. `기획서/기획서.md`는 초기 방향으로 참고했으며 원본은 수정하지 않았다. **작품에 관계없이 보유 카드로 덱을 구성**하고, 소환·효과·체인을 조합해 전개한다. 타이틀과 메인 메뉴에서 튜토리얼, 덱 편집, 대전, 상점, 설정으로 이동한다.

## 실행

1. Unity Hub에서 이 폴더를 프로젝트로 추가한다. 기준 버전은 **Unity 6000.6.0f1**이다.
2. Hub에서 Unity Editor 라이선스가 활성화되어 있는지 확인한다.
3. `Assets/Scenes/DuelPrototype.unity`를 열고 **Play**를 누른다. 에디터 메뉴 `Convergence > Open Duel Prototype`으로도 열 수 있다.
4. 타이틀에서 아무 키나 누르거나 마우스를 클릭해 메인 메뉴로 이동한다.
5. 새 플레이어는 **솔로 모드 → 기본 듀얼**을 완료해 혼합 시작 덱 28장과 150코인을 받는다. 바로 대전을 시험하려면 **솔로 모드 → AI 자유 연습**에서 무료 대여 덱을 사용한다.

게임 화면은 1440×900 기준으로 창 크기에 맞춰 표시된다. 기본 화면은 코드로 그린 임시 UI이며 별도 그림 파일 없이 사용할 수 있다. 한국어 폰트는 운영체제의 맑은 고딕 등을 사용한다.

### 메뉴와 진행

- **게임 시작:** AI 또는 로컬 2인 대전, 선공·후공·무작위, 셔플 시드를 정한다. 내 덱의 매수와 보유 카드 수를 검사한 뒤 시작한다.
- **덱 만들기:** 보유 카드만 편성한다. 스타레일과 원신 등 작품을 섞는 데 제한은 없다. `덱 저장`으로 이 기기에 보관한다.
- **솔로 모드:** 세 단계의 실습을 순서대로 연다. 실제 듀얼 보드에서 안내된 카드와 행동을 직접 사용하고, 실습 상대는 자동으로 진행한다. 복습은 가능하며 보상은 첫 완료에 한 번 지급한다.
- **상점:** 튜토리얼 코인으로 원하는 카드를 1장당 100코인에 구매한다. 같은 카드는 기본 최대 3장까지 보유하며 토큰은 구매할 수 없다.
- **설정:** 전체 음량, 창/전체 화면, AI 행동 간격, 최대 프레임을 저장한다. 현재 오디오 에셋은 없으며 음량 설정은 이후 재생할 게임 소리에 적용된다.

튜토리얼 2는 특수 소환·부활·토큰 지원 카드와 200코인, 튜토리얼 3은 필드·마법·함정 지원 카드와 250코인을 지급한다. **자유 연습은 튜토리얼을 마치거나 카드를 보유할 필요 없이 사용할 수 있다.** 이전 프로토타입에서 저장한 유효한 덱이 있으면 해당 덱과 필요한 카드 보유량을 이어받는다.

### 대전 조작

- **턴 진행:** `다음 페이즈`로 드로우 → 메인 1 → 배틀 → 메인 2 → 엔드를 진행한다.
- **소환·세트:** 패의 카드 선택 → 오른쪽의 일반 소환 또는 인터셉트 세트.
- **효과:** 마법·커맨드 발동 → 안내에 맞는 필드/패의 카드 선택. 부활 대상은 오른쪽 아래 묘지 목록에서 선택한다. 필드 카드는 별도의 플레이어별 1칸에 놓인다.
- **체인:** 상대 행동에 세트한 인터셉트로 응답하거나 `응답 패스`를 누른다. 양쪽이 연속 패스하면 역순으로 해결한다. **AI와 대전해도 자신의 응답은 직접 패스해야 한다.**
- **공격:** 배틀에서 아군 유닛 선택 → 공격 선언 → 상대 유닛 선택. 상대 필드가 비면 상대 LP 옆 `직접 공격`을 누른다.
- **로컬 2인:** 우선권이 바뀔 때 패를 가리는 인계 화면이 나온다. 1번 플레이어는 편집한 덱, 2번 플레이어는 기본 상대 덱을 사용한다.
- **셔플 시드:** 같은 덱과 시드는 같은 시작 상태를 재현한다. 다른 정수를 넣으면 다른 시작 패를 시험할 수 있다.

## 구현한 범위

- 타이틀, 메인 메뉴, 대전 준비, 솔로 모드, 상점, 설정
- 보유 카드로 만드는 20–40장 덱, 동일 카드 최대 3장, 작품 혼합 허용, 덱 저장/복원
- 실제 보드에서 행동하는 튜토리얼 3단계, 첫 완료 보상, 대여 덱 AI 자유 연습
- 캐릭터 8종 + 커맨드 9종 + 인터셉트 3종 + 필드 카드 1종 + 효과로 생성되는 토큰 1종
- 드로우·일반 소환·특수 소환·부활·토큰·강화·피해·회복·파괴
- 턴과 페이즈, 공격력/체력, 지속되는 유닛 피해, 직접 공격, 라이프와 덱 소진 패배
- 응답 우선권, 연속 패스, 체인 역순 처리, 무효화 및 무효화에 대한 대응
- 메인 캐릭터 무작위 선정과 금색 표시, 기본 AI, 로컬 2인
- 필드 카드 `교차하는 세계`: 자신 필드의 유닛 공격력 +300, 새 필드 카드로 교체
- 카드 직접 구매, 카드 보유량·코인·수업 완료·설정 저장, 이전 덱 저장 형식 이전

일반 소환 1회, LP 8000, 시작 패 5장, 선공 첫 턴 공격 제한 등은 **임시 규칙**이다. `Duel Prototype` 오브젝트의 Inspector에 있는 `Rules`에서 바꿀 수 있다. 필드 효과는 현재 공격력 강화 1종을 구현했다. 다른 필드 효과, 카드별 고유 패시브·소속 시너지, 유물·장착, 엑스트라 덱, 가챠, 온라인 대전, 캐릭터 애니메이션은 후속 범위다.

## 검증과 빌드

### 규칙 테스트

.NET SDK 10이 설치되어 있으면 프로젝트 루트에서 실행한다. 외부 NuGet 패키지는 사용하지 않는다.

```powershell
dotnet run --project Tests/Core/Convergence.Core.Tests.csproj
```

현재 **37/37 항목 통과**를 확인했다. 무작위 행동 32판과 기본 AI 8판, 총 **40판 정상 종료**와 세 단계 튜토리얼 흐름을 포함한다. 혼합 덱, 행동 검증, 체인 역순 처리, 무효화의 무효화, 사라진 대상, 승패 후 체인 정리, 필드 효과를 검사한다. 프로필 테스트는 보상의 중복 방지, 상점, 보유 카드 검사, 저장 데이터 복원과 이전을 다룬다.

### Unity 실행 확인

설치된 Unity 6000.6 라이브러리를 참조해 Core·Runtime·Editor 세 어셈블리의 정적 컴파일을 확인했다. 경고와 오류는 0개이며, 재검증 명령은 `Tests/UnityCompile/README.md`에 있다.

Unity 라이선스 문제는 해소되었다. 실제 Unity Editor에서 씬 로드, 기본 규칙 직렬화, AI 대전 8판, 튜토리얼 3개, 프로필 JSON 저장·복원을 확인했다. **Windows 개발 빌드도 성공했으며 `Builds/Windows/Convergence.exe`로 실행할 수 있다.** 기록은 `Artifacts/unity-menu-build.log`에 있다.

자동 검증용으로 창을 숨겨 실행하면 이 환경의 Unity가 IMGUI 화면을 그리지 않아 캡처가 실패한다(`repaints=0`, 종료 코드 2). 따라서 실제 화면 배치와 마우스·키보드 조작은 아직 시각 검증을 마치지 못했다. 게임 창을 표시한 상태에서 아래 캡처 명령 또는 직접 플레이로 확인할 수 있다. 검은 캡처를 성공으로 처리하지 않도록 검사한다.

에디터 메뉴 `Convergence > Build Windows Prototype` 또는 아래 명령으로 Windows 실행 파일을 만든다.

```powershell
powershell -ExecutionPolicy Bypass -File Tools/Build-Prototype.ps1
```

성공하면 `Builds/Windows/Convergence.exe`가 생성된다. `-ValidateOnly`를 붙이면 씬·Unity 내 자동 대전·튜토리얼·프로필 직렬화를 확인한다. 다른 Unity 경로는 `-EditorPath`로 지정한다. Windows는 Direct3D 11을 사용하며 Unity 기본 로고 대신 게임 타이틀로 시작한다.

개발 빌드에는 선택적으로 화면 확인을 자동화하는 인자가 있다. 타이틀·메인·솔로·대전 준비·상점·설정·덱 편집·대전·튜토리얼 완료 화면을 PNG로 저장하고 종료한다. **창을 숨기거나 최소화하지 않고 실행한다.** 검증 모드는 실제 저장 정보를 읽거나 변경하지 않는다. 이 자동 진행은 화면 표시와 내부 행동 흐름을 확인하며 모든 마우스·키보드 조작을 대신 검사하지 않는다.

```powershell
& .\Builds\Windows\Convergence.exe -prototypeSmokeOutput "$PWD\Artifacts\screenshots" -logFile "$PWD\Artifacts\player-smoke.log"
```

이미지와 `smoke-result.txt`를 확인한다. 평소 플레이에는 이 인자를 사용하지 않는다.
