# 컨버전스: 첫 번째 듀얼 프로토타입

`기획서/`의 문서는 수정하지 않는다. 그 문서와 아래 구현 규칙은 모두 발전시킬 수 있는 초기안이다. 이번 단계는 **자유로운 혼합 덱 → 전개 → 상대의 대응 → 전투 → 승패**를 확인하는 데 집중한다. 유희왕 마스터 듀얼을 참고하지만, 현재 수치와 전투 규칙은 이 프로젝트의 임시 규칙이다.

## 덱과 카드

- 덱은 기본 20~40장, 같은 카드 ID는 최대 3장이다. 캐릭터를 최소 1장 포함한다.
- 일반 대전에서는 실제 보유한 수만큼만 덱에 넣는다. 신규 플레이어는 튜토리얼 보상과 상점에서 카드를 얻는다. 튜토리얼과 자유 연습의 대여 덱은 보유량에 관계없이 사용할 수 있다.
- 출전 작품, 소속, 속성은 카드의 설명용 정보다. 스타레일과 원신 캐릭터를 한 덱에서 자유롭게 사용한다.
- 효과의 대상 조건은 카드마다 적용한다. 예를 들어 `아군 유닛`, `패의 캐릭터`, `자신의 묘지 캐릭터`를 구분하지만 작품으로 덱 편성을 제한하지 않는다.
- 캐릭터는 공격력과 체력을 갖는다. 명령(마법·커맨드) 카드는 전개와 지원을 담당하고, 대응(함정·인터셉트) 카드는 뒷열에 세트하여 상대 행동에 개입한다. 필드 카드는 플레이어마다 별도의 한 자리에 유지된다.
- 토큰은 효과로만 생성하며 덱에 넣을 수 없다. 죽은 토큰은 사라지고 부활 대상이 되지 않는다.
- 메인 캐릭터는 덱에 포함된 캐릭터 중 무작위로 정한 표시용 정보다. 선택된 카드를 덱에서 꺼내거나 특별한 능력을 부여하지 않는다.

## 기본 설정

아래 값은 `Assets/Scripts/Core/DuelModel.cs`의 `DuelRules`에서 조정한다.

| 항목 | 기본값 |
| --- | --- |
| 덱 최소 / 최대 크기 | 20 / 40장 |
| 같은 카드 최대 수 | 3장 |
| 시작 패 | 5장 |
| 시작 라이프 | 8000 |
| 플레이어별 유닛 자리 | 5칸 |
| 플레이어별 뒷열 자리 | 5칸 |
| 플레이어별 필드 카드 자리 | 1칸, 유닛·뒷열과 별도 |
| 턴당 일반 소환 | 1회 |
| 선공 첫 턴 드로우 | 생략 |
| 선공 첫 턴 공격 | 불가 |
| 세트한 턴의 대응 카드 발동 | 불가 |
| 유닛 전투의 동시 반격 | 사용 |

샘플 덱은 각각 28장이다. 각 덱은 스타레일과 원신 캐릭터를 합쳐 14장 포함하며, 나머지 14장은 명령 및 대응 카드다.

대전 준비 화면에서 1번 플레이어의 선공·후공·무작위를 고른다. 무작위 선택과 셔플에는 입력한 시드를 사용한다. 같은 덱, 시드, 선후공 선택으로 같은 시작 상태를 재현할 수 있다. 튜토리얼은 학습 목표에 맞춰 정해진 패와 선후공을 사용한다.

## 솔로 모드와 카드 획득

새 프로필은 보유 카드와 코인, 저장 덱이 없는 상태로 시작한다. 타이틀에서 키 입력 또는 마우스 클릭으로 메인 메뉴에 들어간 뒤 솔로 모드를 선택한다.

튜토리얼은 실제 듀얼 엔진과 보드를 사용한다. 안내된 행동과 카드·대상만 진행할 수 있으며 상대 행동은 자동 처리한다. 정해진 전투나 체인 결과까지 해결해야 완료되고 다음 수업이 열린다.

| 수업 | 실제로 하는 행동 | 첫 완료 보상 |
| --- | --- | --- |
| 1. 기본 듀얼 | 일반 소환, 유닛 전투, 지속 체력 확인, 다음 턴 직접 공격으로 승리 | 혼합 시작 덱 28장 + 150코인 |
| 2. 특수 소환과 전개 | 스타레일 캐릭터 일반 소환, 원신 캐릭터 특수 소환, 토큰 생성 | 차원을 잇는 합류 3장, 다시 만나는 동료 2장, 기억의 잔향 2장 + 200코인 |
| 3. 필드 · 마법 · 함정 | 필드 효과, 마법 강화, 함정 세트, 다음 턴 상대 공격에 대응하여 무효화 | 교차하는 세계·작전 교란·전선 사수·함께하는 진격 각 2장 + 250코인 |

- 보상은 수업별 첫 완료에 한 번 지급한다. 다시 연습해도 카드와 코인이 추가되지 않는다.
- 시작 덱 보상은 기존 보유 카드를 유지하면서 필요한 수를 채운다. 저장된 덱이 없을 때 시작 덱을 저장한다.
- 2·3번 수업의 카드 보상은 기존 보유량에 더하되 카드별 최대 3장을 넘지 않는다. 한도를 넘는 카드의 별도 코인 교환은 없다.
- 세 수업의 코인 보상은 합계 600코인이다.
- 상점에서는 토큰을 제외한 카탈로그 카드 중 원하는 카드를 1장당 100코인에 구매한다. 카드별 보유 한도는 기본 3장이다. 코인 부족, 알 수 없는 카드, 이미 보유 한도에 도달한 구매는 상태를 바꾸지 않는다.
- **AI 자유 연습은 처음부터 열려 있다.** 무료 대여 덱을 사용하며 카드를 지급하거나 소비하지 않는다. 현재 일반 대전과 자유 연습에는 반복 코인 보상이 없다.

보유 카드·코인·완료 수업·저장 덱·설정은 이 기기의 프로필에 저장한다. 이전 버전의 유효한 저장 덱은 그대로 가져오고 필요한 카드 보유량을 채운다. 이 이전 작업으로 튜토리얼을 완료 처리하거나 코인을 지급하지 않는다.

## 한 턴의 흐름

1. **드로우:** 패에 카드를 보충한다. 선공의 첫 턴은 생략한다.
2. **메인 1:** 일반 소환, 명령·필드 카드 사용, 대응 카드 세트를 한다.
3. **배틀:** 공격 가능한 유닛으로 공격을 선언한다.
4. **메인 2:** 전투 이후 전개와 세트를 한다. 일반 소환 횟수는 메인 1과 공유한다.
5. **종료:** 다음 플레이어에게 턴을 넘긴다.

명령의 특수 소환과 부활은 일반 소환 횟수를 소비하지 않는다. 필드가 가득 차면 추가 소환은 할 수 없다. 소환된 턴에도 공격할 수 있으며, 선공 첫 턴 공격 금지와 각 유닛의 턴당 공격 횟수 제한을 따른다.

## 전투

- 상대 필드에 유닛이 있으면 그 유닛을 공격한다. 비어 있으면 상대 라이프를 직접 공격한다.
- 유닛끼리 전투하면 공격자와 방어자가 동시에 서로의 공격력만큼 체력 피해를 준다. 방어자가 쓰러지는 전투에서도 반격 피해가 발생한다.
- 체력은 전투 이후에도 유지된다. 기본 규칙에는 턴 시작 시 체력 자동 회복이 없다.
- 체력이 0 이하가 된 캐릭터는 묘지로 이동한다. 공격의 남은 피해가 플레이어 라이프로 넘어가지는 않는다.
- 카드 수치와 효과는 밸런스 검증용이다. 캐릭터 고유 패시브는 아직 적용하지 않는다.

## 대응과 체인

1. 턴 플레이어가 명령·필드 카드 발동 또는 공격을 선언하면 체인이 시작된다.
2. 우선권을 가진 플레이어는 발동 가능한 대응 카드를 사용하거나 패스한다. 다음 우선권은 상대에게 넘어간다.
3. 대응이 추가되면 연속 패스 횟수가 초기화된다. 양쪽이 연속으로 한 번씩 패스하면 체인을 처리한다.
4. **나중에 선언한 행동부터 먼저 처리**한다. 먼저 해결된 대응이 뒤의 공격이나 효과를 무효화할 수 있다.

현재 명령은 속도 1로 취급한다. 자신의 메인 단계에서 새 체인을 시작할 때만 사용하며, 이미 진행 중인 체인에 명령을 이어 붙일 수 없다. 대응 카드는 미리 세트해 두어야 하고 기본 설정에서는 세트한 턴에 발동할 수 없다. `전선 사수`는 직전 링크가 공격일 때 그 공격에 직접 대응한다. 공격 뒤에 다른 대응 카드가 추가되었다면 그 위에 사용할 수 없다.

## 필드 카드

- 필드 카드는 자신의 메인 단계에서 패에서 발동한다. 명령 카드처럼 새 체인을 시작하며 상대는 대응 카드로 개입할 수 있다.
- 플레이어마다 필드 카드 전용 1칸을 사용한다. 유닛 5칸과 대응 카드 5칸을 차지하지 않는다.
- `교차하는 세계`가 유지되는 동안 그 플레이어의 유닛은 공격력 +300을 받는다. 토큰과 나중에 소환된 유닛도 적용되며 상대 유닛에는 적용되지 않는다.
- 새 필드 카드가 정상 해결되면 기존 필드 카드는 묘지로 이동하고 새 카드가 자리를 차지한다. 새 카드의 발동이 무효화되면 기존 필드 카드는 그대로 남는다.
- 필드 강화와 `함께하는 진격` 같은 개별 유닛 강화는 함께 적용된다. 필드 효과가 사라지거나 유닛이 필드를 떠나면 해당 필드 강화도 제거된다.
- 현재 필드 효과는 이 공격력 강화 1종이다. 다른 지속 효과나 복잡한 필드 규칙은 후속 범위다.

### 작품을 섞는 전개 예시

1. `단항`을 일반 소환한다.
2. `차원을 잇는 합류`로 패의 `노엘`을 특수 소환한다. 작품이나 속성이 달라도 같은 대상 조건을 적용한다.
3. 이전 전투에서 묘지로 간 `엠버`가 있다면 `다시 만나는 동료`로 부활시킨다.
4. `기억의 잔향`으로 토큰을 추가한다. 이 예시에서는 필드 5칸 중 4칸을 사용한다.
5. 상대가 대응하지 않거나 대응이 해결된 뒤 배틀로 진행한다.

각 명령은 별도의 체인을 시작한다. 매번 양쪽의 대응과 패스 처리를 마친 뒤 다음 명령을 사용한다. 패, 묘지, 필드 자리와 상대 대응에 따라 이 순서가 항상 가능한 것은 아니다.

## 이후에 결정할 기능

- 유물·장착 카드, 다른 종류의 필드 카드와 지속 효과
- 복잡한 캐릭터 패시브, 특정 소속의 조합 효과, 캐릭터별 스킬 구현
- 엑스트라 덱과 별도 소환 방식
- 추가 카드 획득 경로와 반복 보상, 가챠, 과금
- 온라인 PvP, 서버 검증, 매칭과 동기화
- 메인 캐릭터 소환 연출, 공격 연출, 마무리 연출과 애니메이션

이 항목들은 기획의 방향을 확인한 뒤 추가한다. 현재 샘플 캐릭터의 숫자 차이를 최종 캐릭터 설계로 보지 않는다.
