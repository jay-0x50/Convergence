# 초기 아트 요청서

현재는 **2D 임시 UI만으로 주요 규칙을 검증할 수 있다.** 아래 이미지는 선택 사항이며, 없어도 로직 개발을 진행한다. 첫 시안은 캐릭터 그림 1~2장과 카드 뒷면 정도면 충분하다. Blender 작업은 지금 필요하지 않다.

## 있으면 바로 쓸 수 있는 이미지

| 자산 | 권장 규격 | 그릴 내용 |
| --- | --- | --- |
| 캐릭터 일러스트 | 768 × 1024 px, 3:4, PNG | 캐릭터를 가운데 배치. 투명 배경을 권장하며 머리와 손 주변에 여백 확보 |
| 카드 프레임 | 768 × 1024 px, 3:4, PNG | 일러스트가 들어갈 가운데는 투명하게. 이름, 효과, 공격력·체력 자리 확보 |
| 카드 뒷면 | 768 × 1024 px, 3:4, PNG | 어느 작품의 덱에도 어울리는 공통 문양 1종 |
| 플레이매트 | 1920 × 1080 px, 16:9, PNG | 위아래 플레이어 영역을 구분하는 배경. 카드와 숫자가 잘 보이는 낮은 대비 |
| 간단한 상태 아이콘 | 128 × 128 px, 정사각형, 투명 PNG | 공격 가능, 공격 완료, 세트 상태를 구분할 수 있는 기호 |

그림에 이름, 수치, 효과 설명을 직접 넣지 않는다. 카드 데이터가 바뀔 수 있으므로 글자와 공격력·체력은 UI에서 표시한다. 프레임은 우선 캐릭터·명령·대응의 3종을 색으로만 구분해도 된다. 플레이매트의 슬롯 테두리는 UI에서 그릴 수 있으므로 배경에 고정해서 그릴 필요가 없다.

## 시안 전달 방식

- PNG 원본을 제공하고, 가능하면 레이어가 있는 작업 파일도 함께 보관한다.
- 파일 이름은 카드 ID에 맞추면 연결하기 쉽다. 예: `march7.png`, `noelle.png`, `card_back.png`.
- 일러스트 1장은 작은 카드로 축소했을 때와 선택한 카드의 확대 화면에서 모두 읽히면 좋다.
- 구도와 전체적인 색감부터 확인한다. 처음부터 모든 샘플 캐릭터를 완성할 필요는 없다.

## 전투 규칙 확정 후 필요한 연출

| 연출 | 이후 필요한 자료 |
| --- | --- |
| 메인 캐릭터 등장 | 캐릭터 강조 이미지, 간단한 등장 구도 또는 3~5컷 콘티 |
| 일반 공격 | 타격 방향, 충격 효과, 피격 강조 시안 |
| 스킬 및 대응 | 효과별 색감, 발동 표시, 카드가 강조되는 방식 |
| 마무리 공격과 승패 | 마지막 타격과 결과 화면 콘티 |

이 연출의 길이, 해상도, 애니메이션 형식은 실제 화면과 전투 속도를 확인한 뒤 정한다. 현재 단계에서는 새 일러스트 제작보다 덱 전개와 대응이 재미있는지 먼저 확인할 수 있다.
