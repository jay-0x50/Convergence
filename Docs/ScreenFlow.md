# 화면과 플레이 흐름

이 문서는 현재 구현한 메뉴와 저장 동작을 정리한다. 기획과 카드 수치는 이후 바꿀 수 있다. 게임 화면은 코드로 그린 임시 UI이며, 완성 디자인과 캐릭터 애니메이션은 별도로 교체할 수 있다.

## 처음 실행할 때

1. 타이틀에서 아무 키나 누르거나 마우스를 클릭한다.
2. 메인 메뉴에서 **솔로 모드**를 선택한다.
3. 첫 수업 **기본 듀얼**을 진행한다. 오른쪽 아래 안내와 금색으로 표시된 카드·버튼을 따라 일반 소환, 공격, 체인 패스를 직접 실행한다.
4. 마지막 직접 공격까지 해결하면 혼합 시작 덱 28장과 150코인을 받는다. 처음 받은 시작 덱은 저장 덱으로 등록된다.
5. **덱 만들기**에서 구성을 바꾸거나 **게임 시작**에서 대전을 준비한다. 솔로 모드의 다음 수업도 열린다.

새 프로필은 카드와 코인이 없는 상태다. 첫 수업을 하기 전에 대전을 보고 싶으면 **솔로 모드 → AI 자유 연습**을 선택한다. 무료 대여 덱으로 즉시 연습할 수 있다.

## 메인 메뉴

| 버튼 | 화면과 행동 |
| --- | --- |
| 게임 시작 | 내 덱으로 AI 또는 로컬 2인 대전을 준비한다. |
| 덱 만들기 | 보유 카드로 20–40장 덱을 구성하고 저장한다. |
| 솔로 모드 | 세 단계 튜토리얼과 대여 덱 AI 자유 연습을 선택한다. |
| 상점 | 튜토리얼 코인으로 원하는 카드를 직접 구매한다. |
| 설정 | 음량, 화면 모드, AI 행동 간격, 최대 프레임을 바꾼다. |
| 타이틀로 | 타이틀 화면으로 돌아간다. 저장된 보유 카드와 진행도는 유지된다. |

메인 메뉴에는 보유 카드 수, 코인, 완료한 수업 수, 현재 덱 매수가 표시된다.

## 덱 만들기

- 라이브러리에서 카드 이름·작품·종류로 검색하고 `+ 추가`로 넣는다. 덱 목록의 `−`로 뺀다.
- 카드별로 **보유한 수**와 **동일 카드 최대 3장** 제한을 적용한다. 작품·소속·속성에 따른 편성 제한은 없다.
- 출전 가능한 덱은 20–40장이고 캐릭터가 1장 이상 필요하다. 토큰은 편성 대상이 아니다.
- 시작 덱 불러오기는 해당 카드를 보유하고 있을 때 사용할 수 있다. 편집만으로 카드를 지급하지 않는다.
- `덱 저장`은 유효한 현재 구성을 프로필에 저장한다. 편집 중인 구성을 다음 실행에도 쓰려면 저장해야 한다.

## 대전 준비와 결과

1. **AI 대전** 또는 **로컬 2인 대전**을 고른다.
2. 1번 플레이어의 **선공 / 후공 / 무작위**를 고른다. 선공 첫 턴에는 드로우와 공격을 생략한다.
3. 정수 셔플 시드를 입력하거나 새로운 시드를 만든다. 같은 덱·시드·선후공 선택은 같은 시작 상태를 만든다.
4. 덱 검증을 통과하면 **듀얼 시작**을 누른다. 대여 덱 자유 연습은 보유량 검사 없이 준비된 연습 덱을 사용한다.
5. 대전이 끝나면 대전 설정 또는 메인 화면으로 돌아간다.

로컬 2인은 하나의 기기에서 번갈아 조작한다. 1번 플레이어는 선택한 덱, 2번 플레이어는 기본 상대 덱을 사용한다. 턴이나 체인 응답 우선권이 넘어갈 때 화면을 가리고 다음 플레이어가 준비 완료를 눌러 자신의 패를 확인한다.

일반 대전과 자유 연습은 현재 카드나 코인을 소비하지 않으며 승리 반복 보상도 없다.

## 솔로 튜토리얼

튜토리얼은 실제 듀얼 보드에서 진행한다. 행동 종류, 카드, 대상이 현재 안내와 일치해야 다음 단계로 넘어간다. 상대의 소환·공격·패스는 자동으로 실행된다. 최종 보드 상태나 승리 조건을 확인한 뒤 수업 완료 화면이 나온다.

| 수업 | 실습 목표 | 첫 완료 보상 |
| --- | --- | --- |
| 기본 듀얼 | 소환 → 유닛 전투 → 다음 턴 직접 공격으로 승리 | 혼합 시작 덱 28장 + 150코인 |
| 특수 소환과 전개 | 다른 작품 캐릭터의 특수 소환과 토큰 생성 | 특수 소환·부활·토큰 지원 카드 + 200코인 |
| 필드 · 마법 · 함정 | 필드 카드와 마법으로 강화하고 다음 턴 함정으로 공격 무효화 | 필드·강화·무효화 지원 카드 + 250코인 |

이전 수업을 완료하면 다음 수업이 열린다. 완료 화면에서 복습, 솔로 메뉴, 다음 수업으로 이동한다. 마지막 수업에서는 덱을 확인할 수 있다. 보상은 수업별 한 번이며, 다시 연습하거나 재실행해도 중복 지급되지 않는다. 카드별 수량과 한도 처리는 [구현 규칙](PrototypeRules.md)에 정리했다.

## 상점

카드 이름이나 작품으로 검색해 원하는 카드를 선택한다. 토큰을 제외한 카드는 **1장당 100코인**이며 같은 카드의 보유 한도는 기본 3장이다. 코인이 부족하거나 보유 한도에 도달하면 구매할 수 없다. 구매한 카드와 차감된 코인은 즉시 프로필에 저장한다. 현재 상점은 정해진 가격으로 직접 구매하는 방식이며 무작위 팩과 실제 결제는 구현하지 않았다.

## 설정

| 설정 | 현재 조작과 적용 |
| --- | --- |
| 전체 음량 | 0–100%. 저장 시 게임 전체 음량에 적용한다. 현재 오디오 에셋은 없으며 이후 재생할 소리에 적용된다. |
| 화면 모드 | 창 모드 / 전체 화면. 화면 전환은 빌드된 게임에서 적용한다. |
| AI 행동 간격 | 슬라이더로 상대 행동 사이의 간격을 조절한다. 튜토리얼 상대에도 적용한다. |
| 최대 프레임 | 30 / 60 / 120 FPS 중 선택한다. |

`기본값으로`는 편집 중인 값을 기본 설정으로 바꾼다. `저장 후 돌아가기`를 눌러 적용하고 보관하며, `취소`는 편집한 값을 적용하지 않고 돌아간다.

## 저장과 이전 버전 연결

- 프로필은 Unity `PlayerPrefs`의 `Convergence.Prototype.Profile.v1`에 저장한다. 보유 카드, 코인, 완료 수업, 저장 덱, 설정을 포함한다.
- 새 프로필이 없고 이전 `Convergence.Prototype.Deck.v1` 저장 덱이 있으면 덱 규칙을 검사한 뒤 가져온다. 해당 덱을 편성할 수 있도록 필요한 카드 보유량을 채운다.
- 이전 덱을 가져와도 튜토리얼 완료 여부와 코인은 바뀌지 않는다. 기존 덱으로 대전하면서 수업을 순서대로 진행할 수 있다.
- 불러올 때 알 수 없는 카드·토큰 보유·중복 보유량·잘못된 설정을 정리한다. 저장 덱이 유효하지 않으면 보유 카드로 구성 가능한 시작 덱을 사용하고, 그것도 불가능하면 빈 덱으로 시작한다.
- 저장은 현재 기기에만 적용된다. 계정 로그인과 클라우드 동기화는 후속 범위다.
- 저장 권한 문제로 기록하지 못하면 안내를 표시하고 실행 중인 진행은 유지한다. 종료 전에 저장 문제를 해결해야 다음 실행에도 진행을 유지할 수 있다.

## 확인 범위

규칙·튜토리얼·보상·필드 효과는 자동 테스트로 점검하고, Unity 어셈블리 컴파일 및 실제 씬의 자동 대전을 별도로 확인한다. 화면별 캡처와 조작 확인은 빌드된 게임에서 진행한다. 최신 검증 결과와 명령은 [README](../README.md)의 검증 항목을 따른다.
